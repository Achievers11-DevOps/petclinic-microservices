# Prometheus and Grafana Monitoring Evidence

## Objective
To monitor application performance and system metrics for the PetClinic microservices platform.

## Tools Used

- Prometheus
- Grafana

## Metrics Collected

- CPU usage
- Memory usage
- JVM metrics
- Request counts
- Application uptime

## Grafana Dashboard
The Grafana dashboard was configured to visualize metrics collected from Prometheus.

## Monitoring Workflow

1. Prometheus scrapes metrics from services.
2. Metrics are stored in Prometheus.
3. Grafana queries Prometheus.
4. Dashboards display visualized metrics.
