# Live Demo Script

## Pre-Demo Checklist

- Verify Docker is running
- Verify Kubernetes cluster is active
- Verify all pods are healthy
- Verify Grafana and Prometheus are accessible

## Demo Steps

### Step 1 — Introduce Project
Explain the purpose of the PetClinic Microservices application.

### Step 2 — Show Architecture
Present the architecture diagram and service communication flow.

### Step 3 — Show Kubernetes Cluster
Run:
kubectl get pods

### Step 4 — Show Application
Open the PetClinic UI in the browser.

### Step 5 — Demonstrate Monitoring
Open Grafana dashboards and explain metrics.

### Step 6 — Demonstrate CI/CD
Show GitHub Actions build history and successful workflow runs.

## Backup Plan

If Kubernetes deployment fails:
- Use local Docker Compose deployment
- Use screenshots as fallback evidence

## Final Verification
Ensure all services remain healthy during the presentation.
